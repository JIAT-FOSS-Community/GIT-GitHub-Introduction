## 🔮 Welcome to Open Sourcery

This repository holds the magical artifacts from our **Sorcerer Sessions: Introduction to Git & GitHub**. Hosted by the Java Institute for Advanced Technology (JIAT) and FOSS.LK, this session was crafted to help beginners step into the realm of open-source and version control.

🧙‍♂️ **Presented By:** Charaka Hashan Amarasekara (Founder, JIAT FOSS Community)
📅 **Date:** September 13, 2026
🔗 **Event Link:** [Luma Event Registration](https://luma.com/v7l4kcyj)

## 📜 What's Inside the Cauldron?

This repository contains everything you need to brew up some open-source magic:

- 🧪 **Interactive Presentation:** The complete presentation used during the Sorcerer Session.
- 🪄 **Presentation Slides (`.pptx`):** Downloadable slides for offline learning.
- 🌿 **Open-Source Standard Templates:** Example `CONTRIBUTING.md` and `LICENSE.md` files to help you understand how open-source projects operate.

## ⚔️ Getting Started

Want to learn? We made this for anyone who wants to jump in! You can view the presentation directly via our [GitHub Pages link](https://jiat-foss-community.github.io/GIT-GitHub-Introduction/) (once deployed). 

If you want to contribute or experiment, simply clone the repository and start casting spells:

```bash
git clone https://github.com/JIAT-FOSS-Community/GIT-GitHub-Introduction.git
cd GIT-GitHub-Introduction
```
